Warum nur 100 Plätze?

Weil wir jeden Erstnutzer ernst nehmen wollen. Die erste Generation von Sable geht an 100 Leute, deren Feedback direkt in die nächste Version fließt. Der Zähler oben ist keine Marketing-Zahl — er wird live aus den tatsächlich eingelösten Codes berechnet.

  • Keine Konten. Diese Seite kennt dich nicht und will dich nicht kennen. Kein Tracking, keine Cookies, keine Newsletter-Falle.
  • Codes sind geschützt. Die Prüfung läuft serverseitig, ratenbegrenzt und wird protokolliert. Kein Code ist im Seitencode enthalten.
  • Einmal ist einmal. Jeder Code lässt sich technisch garantiert nur ein einziges Mal einlösen — auch bei gleichzeitigen Versuchen.

    Fragen, ehrlich beantwortet.

    Was brauche ich, um Sable zu nutzen?

    Einen Windows-PC (Windows 10/11) mit mindestens 16 GB RAM — empfohlen 32 GB — und Ollama (kostenlos). Das KI-Modell läuft komplett auf deiner Hardware; je stärker der Rechner, desto flotter die Antworten.

    Läuft wirklich alles lokal?

    Ja. Screenshots, Fragen und Antworten bleiben auf deinem Gerät. Einzige Ausnahme: die optionale Websuche — die ist ab Werk aus, und wenn du sie aktivierst, zeigt Sable für jede Online-Anfrage sichtbar 🌐 statt 🔒.

    Was passiert nach der Code-Einlösung?

    Du bekommst sofort den Download-Link und eine Beleg-ID. Kein Konto, keine E-Mail-Pflicht. Die Beleg-ID ist dein Nachweis, falls du später Support brauchst.

    Kann ich meinen Code weitergeben?

    Solange er nicht eingelöst ist: ja, er ist übertragbar wie ein Schlüssel. Nach der Einlösung ist er dauerhaft verbraucht — genau einmal gültig, ohne Ausnahme.

    Mein Code funktioniert nicht — was nun?

    Prüfe zuerst Tippfehler (Codes enthalten nie 0, O, 1 oder I). Wird der Code als „bereits eingelöst“ gemeldet, obwohl du ihn nie benutzt hast, melde dich mit deinem Kaufnachweis — jede Einlösung ist bei uns auditierbar, wir finden das heraus.
